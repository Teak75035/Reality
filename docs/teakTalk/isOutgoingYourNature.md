# 为什么会有人是自来熟啊？

我常常在厕所里思考这么一个问题：

为什么同样是人，性格上的差距能大过地球和太阳的区别呢？

事实是，有的人就是很开朗，或是我们常说的「E人」。另外的人，比如像我这样的「I人」，恐怕这辈子都理解不了。

为什么会有人是自来熟啊？

欸，你先别急着反驳，如果你也是个比较内向的人，请你想象一下下面的场景：

``` text
一个此前不认识的人，突然间蹿到你身边，
好像和你八百年前就是拜了把子异父异母的亲兄弟姐妹，
从你平时的生活如何侃到你怎么还没结婚……
```
> *你可以复制下来去拷问一下你的朋友，如果他觉得这很正常，你可要小心了，他是个超级大阳角，除非你也这么觉得。*

我的心里应该只会想：

上帝在吗，搞个地缝我钻一下。

不说二人毫无关系这一点，就算是有关系，这样的场面也是我招架不住的。换句话说，我觉得这个人没有边界感。

这里的「没有边界感」并不是一个贬义词，而是不少人都或多或少存在的现象。

没有边界感的人会想方设法地接近你，但你不一定也是个裸露的原子核，你们俩也不一定能靠作用力吸在一起。

如果是像我这样斥力巨大的原子核，估计只想着怎么离这个人远一点。

当然，我见过两个阳光开朗大男孩真的能互相绑定的，但那也是少之又少，至少以我的阅历来看是这样。

换句话说，谁心里没有点防线啊？

被人离得太近，会产生一种不安全感，这是几乎所有人都会感受到的现象。而这时候，心理学家就有出场的机会了。

欸，给它取个名字，叫**社交距离**吧！这将是心理学的伟大发现！

> *（其实这是实际的距离量，对，单位是米）*

不过为了方便~~我瞎扯~~理解，我们也用它来表示心理上的距离吧！

每个人的社交距离有大有小，和外向内向也并完全不是绝对的线性关系。

> *你可以尝试用相关系数验证一下，如果你很闲的话，论文发表一定记得挂我一个八作。*

你可以把人想象装在一个泡泡里，而社交距离就是它的半径。

一般来说，距离越大的人越排斥别人在心灵上靠近，就像是戳破了泡泡一样，换句话说就是所谓的「套近乎」；而距离越小的人，边界感越弱，他们对这种原子核引力式的靠近并不怎么反感，因为他们本身泡泡就够小，你一般摸不到。

泡泡也可以象征社交中的安全感。当泡泡被戳破时，安全感就消失殆尽了，相反，你会有一种很难受的感觉，像是浑身有蚂蚁在爬。

那一定有聪明的读者要问了：

啊绫宫绫宫你说这么久了有实例吗？

你别说还真有，供各位共情一下。我自己就是个社交距离极大的小炸弹。

> *如果我被戳了泡泡的话，大概率我以后都不会主动找这个人了。（不说话装高冷）*

首先登场的是——**电梯**。

我相信应该有人懂，电梯是世界上最尴尬的地方，没有之一。尤其是当整个电梯只有你和一个陌生人的时候，那几十秒简直比一个世纪还要漫长。

你会假装看手机、假装看楼层、假装看电梯广告，总之就是假装自己很忙，忙到根本没有时间跟任何人说话。

结果就在你祈祷电梯快点到的时候，对方突然开口了：

"哎，你也住XX楼啊？"

我当时心里咯噔一下，我的泡泡被戳了一个小窟窿。我只能挤出一个标准的职业假笑："嗯。"

我以为这就是极限了，结果对方直接开启了查户口模式：

"你是哪个学校的啊？"

"你多大了啊？"

"你怎么还不找对象啊？"

？等会你在说什么啊？

我整个人僵在那里，手里的手机都快被我捏变形了。浑身的鸡皮疙瘩都起来了，脑子里只有一个念头：电梯怎么还不到？怎么还不到？怎么还不到？

> *我当时甚至在想，如果我现在假装突发心脏病，会不会有人信？*

**奶茶店**也是个好地方啊，不知道你们有没有经历过。

就是在等奶茶制作的时候，喜欢站在一边低头看手机。

结果我后面的一个女生突然拍了拍我的肩膀：

"哎姐妹，你觉得这个好喝还是那个好喝啊？"

如果我开口了，那接下来就会是：

"真的吗？我上次喝了那个，觉得太甜了。你平时喝几分糖啊？"

"哦你也喝三分糖啊！太巧了！我也是！"

"你是学生吗？还是已经工作了？"

"你住这附近吗？我就住前面那个小区！"

我当时真的想原地挖个地缝钻进去。我只是想安安静静买杯奶茶而已啊！为什么要跟我聊这么多啊！

> *最后我拿到奶茶之后，直接逃离了现场就是了。*

还有一个就是**公交车**，特别是那些嘴很溜的大爷大妈。

这个我真的是服了。我坐公交车最喜欢的就是后排靠墙的位置，可以戴上耳机什么都不想。

结果我旁边坐了一个大叔，从上车开始就一直在跟我说话。

"小姑娘你去哪里啊？"

"哦去XX啊！我也去！太巧了！"

"你一个人去吗？女孩子一个人出门不安全啊！"

"我跟你说啊，XX那个地方啊……"

我全程戴着耳机，把音量调到最大，假装在听音乐，偶尔点点头。结果他居然伸手把我的耳机摘下来了！

"哎小姑娘，我跟你说话呢！你怎么不理我啊？"

我当时真的是又生气又尴尬。我感觉我整个人都要炸了。我只能用我这辈子最冷漠的语气说："不好意思叔叔，我有点累，想睡一会儿。"

然后我就戴上眼罩，假装睡觉，一直睡到下车。

其实冷静下来想想，这些自来熟的人真的没有什么恶意。他们只是可能觉得跟别人聊天是一件很开心的事情，想分享自己的生活，或者只是单纯地觉得无聊，想找个人说说话。

但是对于我们这种社交距离极大的I人来说，这种没有边界感的靠近，那真的是一种折磨。

就像我之前说的，每个人都有自己的泡泡。有的人的泡泡很小，甚至没有泡泡，他们可以很轻松地跟别人打成一片；有的人的泡泡很大，他们需要足够的空间和距离才能感到安全。

这两种人没有谁对谁错，也没有谁好谁坏。只是我们的社交方式不一样而已。

如果一个泡泡小的人遇到了另一个泡泡小的人，那他们可能会成为很好的朋友，甚至是灵魂伴侣；如果一个泡泡小的人遇到了一个泡泡大的人，那可能就会出现我上面说的那些尴尬的场面。

所以啊，下次如果你遇到了一个自来熟的人，而你又觉得不舒服的话，不妨直接告诉对方："不好意思，我不太喜欢跟别人聊这些。"

不用觉得不好意思，也不用勉强自己。保护好自己的泡泡，才是最重要的。

当然，如果你是一个自来熟的人，也请你稍微注意一下别人的反应。如果对方表现得很冷淡，或者一直在回避你的问题，那可能就是对方的社交距离比较大，你需要稍微保持一点距离。

互相尊重，才是最好的社交方式。

换一种眼光去看，其实社交距离大小也是有各自的好处的。这也不是一个非黑即白的事儿，每个人都有自己的社交方式，只要双方都觉得能接受，那就是 OK 的。

话说回来，你觉得自己属于哪一种社交距离？
