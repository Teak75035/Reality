## 为什么创建这个平台
说实话，这个问题其实很简单：因为我有想要分享的东西。不管是解决问题总结出的方法，还是创作出的文字，亦或者只是心里的一些想法，我觉得它们有**被看见的价值**，也应该有**被看见的权利**。

这个平台会持续收录这些内容，当然，如果你有好的内容想要分享，也欢迎将它发布在 Reality 中。

> 毕竟现实世界并不属于任何个体，而是属于每个人。

## 如何发布文章 / 文档
以下有两种方式供你选择。

1. 前往 GitHub 仓库提交

    你可以访问 Reality 的 [GitHub 页面](https://github.com/Teak75035/Reality) 并通过 Pull Request 向 Reality 添加文档。

2. 将文章 / 文档传输给椎名绫宫

    如果你没有 GitHub 使用习惯或并不方便使用，你可以将它分享给椎名绫宫，由椎名绫宫添加到 Reality 内。
